## Scope
`capture_environment() -> EnvironmentInfo` (pydantic model defined in this file), serialisable to `environment.json`.

Fields (plan.md s3.4): OS, kernel, CPU model, core count, governor (Linux; `null` + reason elsewhere), Docker version, Docker VM resources (CPUs, memory), image digests (passed in as a mapping), runtime versions (python, k6), CPU allocation (passed in), git SHA of the experiment (`null` if not a repo), plus `cpu_pinning_reliable: bool` and `comparability: "canonical" | "not-cross-machine-comparable"`.

Rule: macOS or Docker Desktop => `cpu_pinning_reliable=false` and `not-cross-machine-comparable`. Unknown values are `null` with a reason string, never guessed defaults.
