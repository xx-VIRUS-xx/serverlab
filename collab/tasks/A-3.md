## Scope
Integration test proving Week 1 acceptance: with VUs deliberately starved (`maxVUs` far below Little's-law need against the synthetic target), the run is flagged `invalid` with reasons naming dropped iterations and/or maxVUs. Also a control run with ample VUs that is `valid`.

## Acceptance
- [x] Starved run -> `valid == False`, reasons non-empty and specific.
- [x] Control run -> `valid == True`.
- [ ] Test is skipped with a clear message if `k6` is not installed, never silently passes. (Implemented via `pytestmark` skipif on `shutil.which` + `find_k6_binary`; not exercised, since k6 v2.3.0 is installed here.)
- [x] ruff, mypy, pytest clean.
