## Scope
Same lifecycle conventions as `serverlab/metrics/collector.py` (read it first): `AppMetricsCollector(url: str, interval_s: float = 1.0)`, `start(run_id, out_path)`, `stop() -> stats`, never raises into the caller, errors in stats, interval >= 1.0 s enforced with ValueError. Poll `GET url` (stdlib urllib, short timeout) every interval in a background thread. The endpoint returns JSON with cumulative counters and gauges (contract: docs/phases/week4.md section 2; keys: pool_min, pool_max, pool_size, pool_available, requests_waiting, requests_num, requests_queued, requests_wait_ms, requests_wait_max, in_flight, ok, errors).
Per sample write one JSON line: `run_id`, `t_host_utc`, `interval_s_actual` (monotonic time since the previous poll), gauges as read (pool_size, pool_available, requests_waiting, in_flight), and deltas since the previous poll for requests_num, requests_queued, requests_wait_ms, ok, errors, plus `mean_wait_ms` = delta requests_wait_ms / delta requests_queued (null when delta requests_queued == 0). The first poll only primes the baseline (no line). If a counter goes DOWN (app restarted) emit a line with `counter_reset: true` and null deltas, then re-baseline. Failed polls (timeout, connection refused, bad JSON, missing key) are counted in stats (missed_samples, errors) and never produce invented values.
