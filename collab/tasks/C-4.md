## Scope
Implement `MetricsCollector` (`start(run_id, out_path)`, `stop() -> CollectorStats`) per docs/phases/week2.md s2-3. One `docker stats --format '{{json .}}'` streaming subprocess on the host (not inside the SUT), writes one JSON line per container per sample with a host timestamp, interval >= 1 s (reject lower). A failure in the collector must never raise into the caller: record it in `CollectorStats` (samples, missed, errors, interval). Parsing must be unit-tested on fixtures captured from the real `docker stats` on this Mac, not invented numbers.

## Acceptance
- [ ] Real capture of a short run against a running container; paste the first lines of the jsonl.
- [ ] Interval < 1 s raises ValueError at construction.
- [ ] Subprocess is terminated on stop(), and on failure no zombie process remains.
- [ ] ruff, mypy, pytest clean.
