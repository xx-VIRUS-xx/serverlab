## Scope
Minimal async HTTP server with a semaphore of size `CONCURRENCY_LIMIT` and a fixed `SERVICE_TIME_MS` (`asyncio.sleep`). Capacity C = CONCURRENCY_LIMIT / SERVICE_TIME (req/s). Both read from env vars. `/healthz` and `/work`. Expose `/stats` (in-flight, queued, completed) so tests can verify saturation.

No randomness in service time (known capacity must be exact). Pin the base image by digest in the Dockerfile.
