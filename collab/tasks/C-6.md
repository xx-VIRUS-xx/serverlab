## Scope (contract: docs/phases/week4.md section 2)
FastAPI app served by uvicorn with ONE worker. Env config: `DATABASE_URL`, `POOL_SIZE` (min_size == max_size == POOL_SIZE), `SERVICE_TIME_MS` (default 50), `POOL_TIMEOUT_S` (default 30), `PORT` (8000).
- `GET /work`: acquire a connection from `psycopg_pool.AsyncConnectionPool`, run `SELECT pg_sleep(%s)` with SERVICE_TIME_MS/1000, release, return `{"status":"ok"}`. No max_waiting cap: excess requests queue. A pool timeout or DB error returns 503 and increments `errors`; never crash the process.
- `GET /healthz`: 200 only after the pool is open and a `SELECT 1` succeeded; otherwise 503.
- `GET /metrics`: JSON with the cumulative counters from `pool.get_stats()` (pool_min, pool_max, pool_size, pool_available, requests_waiting, requests_num, requests_queued, requests_wait_ms, requests_wait_max, and any other keys get_stats returns) plus app counters `in_flight`, `ok`, `errors`. Values are numbers, never strings.
- Pool opened in the FastAPI lifespan (`open=False` in the constructor, then `await pool.open(wait=True)`), closed on shutdown. No access logging (uvicorn `--no-access-log`, log level warning).
Dockerfile: `FROM python:3.12.4-slim@sha256:a3e58f9399353be051735f09be0316bfdeab571a5c6a24fd78b92df85bcb2d85`; install from `requirements.txt` with EXACT pinned versions (fastapi, uvicorn, psycopg[binary,pool]; resolve once, then pin what you installed); copy app.py; CMD uvicorn with --workers 1. Build context is the repo root (like targets/synthetic).
